# Decisions

Product and architecture decisions about the new reader (`reader-next/`), newest first. A decision that changes behaviour
from sefaria.org's legacy reader is recorded here; the matching atlas entries (`docs/features/`) carry the detail.

D-1 … D-12 are the launch decisions of 2026-11-09; L0 is the staff opt-in and L1 the public opt-in for signed-in users.

| 2026-11-11 | api-data, accounts, platform                               | **Three additive shared-API changes also reach the Voices host (accepted).** These are served from `sefaria/urls_shared.py` or shared helpers, so they apply on both hosts; no Voices code changes. (1) Every `/api/v2/topics/<slug>` answer gains a `pools` list (`sefaria/helper/topic.py`); the legacy client reads `pools` only on link and table-of-contents items, so legacy behaviour is unchanged; v1 `/api/topics/<slug>` is unchanged. (2) The password-reset resend change (next row). (3) Four new routes: `/api/library-assistant`, `/api/topics-toc`, `/api/topics/library-count`, `/api/activity/<tref>/<lang>/<version>` (`/api/topics/library-count` used to fall through to `api/topics/<path:topic>` and answer `{}`). Recorded exception to the 2026-11-10 rule that no change touches the Voices host. | owner        |
| 2026-11-11 | accounts                                                   | **Password-reset resend hardening is kept; the page's wording is fixed.** "Request New Link" on the expired-link page mails a new link only to the holder of a genuine expired token (or a session holding a recent proof), at most 3 an hour, and answers `200 {}` in every case, so a link's `uid` can no longer be used to mail-bomb an account or learn whether it exists. A link that was already used, or issued before the user's last sign-in, gets no new email; the page's wording no longer promises one. Applies to the Library and Voices hosts from the first production deploy.                                                                                                                                                                                                                              | owner        |
