## What was found and fixed by this run
- **Hebrew text face** — the rebuild drew Hebrew in Heebo (a `:lang(he)` UI rule in base.css overrode the text face, also on nested
  elements). Now Taamey Frank CLM first, as sefaria.org. Citation links inside commentary got the old letter-spacing (1px).
- **Phone width** — a panel narrower than 730px (old `narrowColumn`) keeps the text 26px further from its edges: the text runs from
  x=56 to x=334 at 390px (was 30 to 360). Implemented with a container query on the panel, so it also applies to side-by-side panels.
- **Segment numbers, language fallbacks, mis-nested footnotes** — see the text parity entries in the CHANGELOG.

## Remaining differences, explained
| Difference | Why | Decision |
|---|---|---|
| English text is Cardo, sefaria.org's is Adobe Garamond Pro | Adobe Garamond is licensed through Adobe Fonts (Typekit) and cannot be bundled; Cardo is the open face already first in the old stack for Greek. Lines break a few words earlier on the live site. | **Owner to decide**: keep Cardo, or use EB Garamond (open licence, closer to Garamond metrics), or license Adobe Fonts for this client. |
| Text colour #121212 (live: black), secondary #707070 (live: #666) | Tokens chosen for light/dark parity and contrast (WCAG AA on the grey panel header) | Intentional |
| Live pages have a Library Assistant banner, donation modal, cookie notice and a "change translation" bar | Out of scope for the reader surface | Not built |
| Page markers (Vilna/Venice) | An empty element with CSS content on the live site; a small text run here. Looks the same | Intentional |
| Live bilingual segments in Hebrew mode show the dot for the link count on the far side | Same in the rebuild (checked visually) | None |
