{% comment %} Appearance: sets before any stylesheet loads, so a page never paints in the wrong theme. The server renders the attribute itself for a light or dark preference (sefaria/system/theme.py); for auto it cannot, because only the browser knows the system setting. Rules (shared with static/js/sefaria/theme.js and sefaria/system/theme.py): * The `theme` cookie holds `auto`, `light` or `dark`. Parsing matches Django's parse_cookie: the last `theme` cookie wins, the value is trimmed and surrounding double quotes are removed. * `light` or `dark` is shown as is. Auto, no cookie and any other value follow prefers-color-scheme, and are light when the browser gives no signal. * When it switches to dark it also updates , so it must be included after that meta tag. * Live system changes after load are handled by watchSystemTheme() in theme.js. Keep it dependency-free (no Sefaria, jQuery or external files), wrapped in try/catch, and small. static/js/tests/themeHeadScript.test.js evaluates these exact bytes and checks the size budget. {% endcomment %}
