{% comment %} Theme safety net: re-applies the stored light/dark choice to before any stylesheet loads, so a page never paints in the wrong theme. The server normally renders the attribute already (sefaria/system/theme.py); this covers templates rendered without it. Rules (shared with static/js/sefaria/theme.js and sefaria/system/theme.py): * The `theme` cookie holds `light` or `dark`. Parsing matches Django's parse_cookie: the last `theme` cookie wins, the value is trimmed and surrounding double quotes are removed. * A valid cookie keeps a valid server-rendered value (the server read the same cookie header); with no valid cookie the page is light. * When it switches to dark it also updates , so it must be included after that meta tag. It only overrides a server-rendered dark page if JS cannot see a cookie that Django saw (an HttpOnly `theme` cookie, which our code never writes); the meta colour is then left for applyTheme() to correct on the next toggle. Keep it dependency-free (no Sefaria, jQuery or external files), wrapped in try/catch, and small. static/js/tests/themeHeadScript.test.js evaluates these exact bytes and checks the size budget. {% endcomment %}
