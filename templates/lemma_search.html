Weight 0 gives the baseline in both lists. At weight 1, both search routes have a multiplier of 1; their raw scores can differ. Phrase flexibility applies equally to the two Elasticsearch lists: 0 requires an exact sequence; 10 allows gaps and some reordering, like ordinary search. First search takes longer while the model loads.

Include י/ו lemma variants: also searches lemma forms found in the corpus that differ by י or ו. Always keeps the original lemmas and searches up to 256 combinations, preferring fewer changed words, fewer letter edits, then more frequent forms. Applies to enhanced search only.

Both lists use the same Dicta response for Hebrew queries, with ordinary search’s replacement and score-merging rules. Dicta hits are labeled and use Dicta’s text version; they have no Shoshan hover annotations. The default phrase flexibility (10) matches ordinary search. Changing it modifies the Elasticsearch part of this comparison. Queries go directly to Dicta, as on the main site.
