# Welcome to Sefaria's Technical Documentation

Please note: For our API Documentation, see [Getting Started With The Sefaria API](https://developers.sefaria.org/reference/getting-started).

This section is home to Sefaria's continuously evolving documentation, offering insights into the intricate structure of texts in the Sefaria Library, as well as related technical aspects such as formatting and accessibility. It also includes documentation of API endpoints that go beyond the [API reference](https://developers.sefaria.org/reference/getting-started), providing you with a richer understanding of our powerful platform.

## Quick Questions and Answers

### Need more information before exploring Sefaria's API?

Read through [Text References](https://developers.sefaria.org/docs/text-references) for background information, then head over to [Getting Started With the Sefaria API](https://developers.sefaria.org/reference/getting-started) to try retrieving some text.

### Interested in the structure of the Sefaria Library?

Explore [The Structure of a Book on Sefaria](https://developers.sefaria.org/docs/the-structure-of-a-text-on-sefaria). We recommend examining [Index and Versions](https://developers.sefaria.org/docs/each-book-is-an-index) and the details within [The Index Schema](https://developers.sefaria.org/docs/the-index-schema) closely for clarity.

### Looking for additional endpoints beyond the [API Reference](https://developers.sefaria.org/reference/getting-started)?

Check out our documentation about the [Shape API](https://developers.sefaria.org/docs/shape-api), [Categories API](https://developers.sefaria.org/docs/categories), and [Search API: Elastic Search Proxy](https://developers.sefaria.org/docs/search-api).
