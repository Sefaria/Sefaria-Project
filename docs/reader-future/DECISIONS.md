# Decisions

Every decision about the future reader, newest first. Written by Claude Tag from a `Decision:` message in **#reader-future** (or an
explicit "this is decided" in a thread), and mirrored in the area's own Decisions section.

| Date | Area | Decision | Decided by | Source |
|---|---|---|---|---|
| 2026-10-28 | analytics, platform-seo (performance) | Real-user monitoring: `web-vitals` (attribution) sends LCP, INP and CLS to GA4, plus Sentry tracing at a low sample rate. Targets: Core Web Vitals "good" at p75 on real phone sessions (LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1); CI lab gate on Pixel 7, 4× CPU, slow 4G. Condition: the existing GA4 data stream stays exactly the same. | Akiva (owner) | Claude Code session; `TARGET_ARCHITECTURE.md` §2 D1 |
| 2026-10-28 | analytics, admin-tools | VWO and Hotjar load according to remote-config attributes, read by both clients; remote config must keep working (its cache must reach every process). Unbounce loads only on the pages that use it. Amends ANL-PAR-1. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D2, §6.5 |
| 2026-10-28 | text-display | Dark mode: follows the device by default with a Light / Dark / System control; sepia dropped at launch; every page the new client renders; stored in the `color` cookie and the profile; content with its own colours on a light surface; behind a remote-config feature flag that can switch it on and off. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D3, §6.6 |
| 2026-10-28 | routing, ai | Integrations: honour `replaceHistory`; a ref closes all panels at launch, optional panel targeting in versioned commands; no cross-origin `postMessage` at launch; reader team owns the interface and contract test, AI team the chatbot side; re-read preferences on focus while `/settings` is Django. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D4, §6.12 |
| 2026-10-28 | i18n-a11y, versions | Preferences: legacy precedence at launch; location guesses are never saved as choices; new profile keys only content language and theme; sign-in merge fills empty profile fields, profile wins; preference cookies on `.sefaria.org`. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D5, §6.4 |
| 2026-10-28 | connections, text-display | Sidebar: parity at launch (segment click opens it); build the seams now; test the docked/own-control model on a cauldron. Word lookup: double-click on desktop; phone gesture open. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D6 |
| 2026-10-28 | reader-shell | From the learning-workspace POC adopt vertical stacks with `layout=`, resizable dividers, drag with a keyboard equivalent, stable panel ids and the phone rule; bookmarks go into the user-state store; right-click menu, focus mode and definition card stay experiments. | Akiva (owner) | `TARGET_ARCHITECTURE.md` §2 D7 |
