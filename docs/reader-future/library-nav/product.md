## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `library-nav`): **69 features** — core 10, standard 49, optional 9, retire 1. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Sidebar modules (41); Category pages (12); Library home (7); Shared navigation components (5); Translations (2); Orphaned pages (1); Sidebar framework (1).

### Core (10)

| ID | Feature | What it does |
|---|---|---|
| LIB-001 | Browse the Library category grid | The texts home page shows every top-level category as a colored card with a short description. Clicking opens that category without a page reload. |
| LIB-008 | Category page contents list | Each category page lists its sub-categories and texts, with a colored top line, title, description and edition attribution. |
| LIB-011 | Talmud and Tosefta edition toggle | Talmud and Tosefta category pages have a toggle to switch between Bavli/Yerushalmi and Vilna/Lieberman editions. |
| LIB-012 | Nested category sections and single-text collapse | Within a category page, primary sub-categories become links, other sub-categories expand inline with their own heading, and a category containing one text shows that text directly. |
| LIB-014 | Text items open book page | Clicking a text in a category opens its table-of-contents page; hidden texts are not listed. |
| LIB-023 | Nav sidebar container and module registry | Navigation pages share a right-hand sidebar built from a configurable list of modules, followed by a footer. |
| LIB-036 | Sidebar module: About this text | Shows book metadata: authors, composition place and date, and description. |
| LIB-065 | Tab view component | Tabbed pages (book page, topics) share an accessible tab control with keyboard navigation and pseudo-tabs. |
| LIB-068 | Library navigation support utilities | Navigation depends on cached TOC helpers, Hebrew term lookup and server-provided props. |
| LIB-069 | Library category URL handling (server) | Server routes for /texts and category paths handle redirects, fallbacks and SEO. |
