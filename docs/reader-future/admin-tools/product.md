## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `admin-tools`): **58 features** — core 3, standard 30, optional 22, retire 3. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Ops Endpoints (8); Linker Admin (8); Inline admin editors (7); Config & Curation Apps (6); Stats & Moderation (5); Inline editors (3); Moderator Tools Page (3); Bulk Text Tools (3); Link Tools (3); Version Tools (3); Disabled Tools (3); Linker admin (2); Inline Editors (2); Editor components (1); Editing Support APIs (1).

### Core (3)

| ID | Feature | What it does |
|---|---|---|
| ADM-029 | Shared admin edit form (AdminEditor) | A reusable editorial form used by the topic, category, collection and source editors, with standard fields, markdown link checking and delete. |
| ADM-053 | Remote config feature flags | Admins change runtime settings and feature flags without redeploying, and the client reads active ones. |
| ADM-057 | Email-as-username authentication | Users log in with email; the underlying username is a hash. |

### Standard (30)

| ID | Feature | What it does |
|---|---|---|
| ADM-003 | Admin edit buttons on headings (CategoryHeader) | Moderators see small add/edit/reorder buttons next to page headings across library and topic pages. |
| ADM-004 | Generic admin editor form shell | A reusable admin form with save/cancel, validation and sanitized inputs powers the category, topic, source and index editors. |
| ADM-005 | Topic editor | Moderators can create, edit, re-parent, illustrate and delete topics and topic categories. |
| ADM-006 | Category editor and reorder | Moderators can create, rename, move, describe, reorder and delete library categories. |
| ADM-007 | Topic source (link) editor | Moderators can add, change or delete a source linked to a topic, including its title and learning prompt. |
| ADM-008 | Index (book info) editor | Moderators can edit a book's titles, descriptions, authors, dates, category and dependence, and rename or delete the book. |
| ADM-009 | Version editor (book page) | Moderators can edit or delete a text version's metadata from the book page Versions tab. |
| ADM-014 | Moderator Tools page (/modtools) | Staff get a single page hosting the live bulk-editing and link-management tools; non-moderators see a notice that tools are moderator-only. |
| ADM-018 | Bulk upload text versions from CSV | Moderators upload one or many CSV files of text; the tool splits multi-book files, uploads each book in turn with progress, then rebuilds the table of contents once. |
| ADM-020 | Upload links from CSV | Moderators bulk-create links between refs from a two-column CSV, choosing link type and project name; errors come back as a downloadable file. |
| ADM-021 | Download links as CSV | Moderators export links between two refs (or from one ref to the whole library) as a CSV, optionally filtered by type and generator. |
| ADM-023 | Bulk edit version metadata | Moderators find every text that carries a given version title and update that version's metadata (license, source, flags, notes) across all of them in one go. |
| ADM-024 | Rename version title across texts | Moderators rename a version title across all selected texts with a typed confirmation; large renames run in the background. |
| ADM-025 | Bulk delete versions (hard delete) | Moderators permanently delete a version from all selected texts after typing a confirmation. |
| ADM-030 | Moderator-only edit buttons in reader | Moderators see edit buttons for topics, categories, collections, sources and index records directly in the reader. |
| ADM-031 | Editing support endpoints (locks, flags, revert, bulk modify) | Behind the editors sit APIs for locking texts, flagging versions, reverting edits, reading history and bulk segment edits. |
| ADM-032 | Cache and rebuild admin URLs | Staff trigger cache resets and rebuilds (library, one text, counts, table of contents, autocompleter, Varnish) by visiting admin URLs, usually landing back on the homepage with a flash message. |
| ADM-033 | Link rebuild admin URLs | Staff regenerate commentary links or citation links for a text, or delete citation links. |
| ADM-038 | Django admin site | Stock Django admin hosts editors for guides, remote config, topic pools, user experiments and other admin-managed models. |
| ADM-039 | Strapi webhooks (CMS cache) | CMS content is cached and invalidated through two webhook endpoints. |
| ADM-042 | Spam review dashboards (sheets and profiles) | Staff review lists of suspected spam sheets and profiles and bulk mark them reviewed or purge them and their owners. |
| ADM-043 | Purge spammer account data | When marking spam, the system quarantines or removes everything the spammer owns and deactivates the account. |
| ADM-044 | Staff delete user account / sheet by id | Staff can delete a user account by email or a sheet by id via password-confirmed forms. |
| ADM-045 | Linker editor page (/linker-editor) | Staff edit per-text linker metadata (match templates, address types, node properties, non-unique terms) in a dedicated editor page. |
| ADM-046 | Edit MatchTemplates per node | Staff add, remove or extend the match templates that tell the linker how a text node can be cited. |
| ADM-047 | Edit AddressTypes per node level | Staff choose how each level of a text is addressed (e.g. chapter, verse, daf) for the linker. |
| ADM-048 | Edit linker node properties | Staff set per-node linker flags such as referenceable, numeric equivalent, dibur hamatchil patterns and skipped addresses. |
| ADM-049 | Manage NonUniqueTerms | Staff view, create, rename, swap and delete the shared terms used in match templates, seeing where each is used. |
| ADM-050 | Rebuild RefResolver and Dibur Hamatchils | Staff trigger rebuilds of the linker's resolver (Hebrew, English or both) and of dibur hamatchil data, with progress polling. |
| ADM-054 | Topic pool and schedule curation (django_topics) | Product staff curate which topics belong to which pools and schedule the topic of the day and seasonal topics in Django admin. |

| ADM-034 | Cache and memory diagnostics | Staff can inspect cache sizes, memory, and force a heap dump or deliberate error for debugging. |

| ADM-036 | Index sheets by timestamp (API key) | An external caller with a staff API key can trigger search indexing of sheets modified since a timestamp. |
| ADM-037 | Update descriptions from Google Sheet | Staff pull author, category and text descriptions from a Google Sheet into the database. |
| ADM-040 | Account and sheet stats pages | Staff view plain-text statistics on account creation, sheets, contributors, and a list of public sheets lacking tags. |
| ADM-041 | Categorize sheets tool | Staff step through public sheets one at a time assigning topics and categories, or marking them as having no tags. |
| ADM-051 | In-reader Linker Admin panel | Moderators open a panel in the reader's tools that shows how the linker resolved a citation and lets them re-run, delete/recreate or reparse it and add training examples. |
| ADM-052 | Linker debug mode (debug_mode=linker) | A debug URL parameter makes the text API return linker output and colors each citation by outcome so moderators can see failures and ambiguities. |
| ADM-055 | Powered-by-Sefaria showcase | Community projects built on Sefaria are submitted via form and listed publicly after review. |
| ADM-056 | Dedications | Dedication pages are editable in admin and rendered at /dedication/<slug>. |
| ADM-058 | Deploy promotion tracking files | Plain text files record the version promoted to each environment for deploy automation. |
