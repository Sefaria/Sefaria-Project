## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `search`): **110 features** — core 41, standard 52, optional 11, retire 6. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Search page (Library) (20); Header autocomplete (19); Entity tabs (Books/Authors/Topics) (12); Entry points (8); Autocomplete backend (8); Search page URL and state (7); Sources search backend (7); Voices sheet search (5); Search analytics (5); Sources filter UI (4); Search in this text (4); Topic and ref autocomplete elsewhere (3); Other search endpoints (3); Dictionary search (2); Caching and accessibility (2); In-book search (1).

### Retire (6)

| ID | Feature | What it does |
|---|---|---|
| SRC-014 | Latent crash on exact Collection/Category Enter | Pressing Enter on an exact Collection name in Library, or TocCategory in Voices, throws an error. |
| SRC-030 | Legacy s1 page search handoff | On legacy pages the header search does a full page load to /search. |
| SRC-059 | qh query-highlight URL param (dead) | Result links carry a qh param that the modern reader ignores, so new-tab/deep-link opens get no highlight. |
