## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `topics`): **32 features** — core 9, standard 18, optional 4, retire 1. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Topic page (18); Topics landing page (8); Topic categories and A-Z (4); Topics routing (2).

### Core (9)

| ID | Feature | What it does |
|---|---|---|
| TOP-001 | Topic URLs and legacy redirects | Topics have landing, category, A-Z and individual topic URLs, and old sheet-tag URLs redirect to topics. |
| TOP-003 | Topics landing page layout | The library's topics home presents search, a word cloud of topics, a featured topic, a newsletter, sample topics and this week's seasonal content. |
| TOP-013 | Topic category page | A topic category page lists its subtopics as cards, sorted and filtered for the current site. |
| TOP-015 | Topic page data loading | A topic page fetches the topic's details, sources, sheets and related links, sorted into tabs. |
| TOP-016 | Topic source tab bucketing | Sources linked to a topic are sorted into Notable Sources, Sources, Top Citations and Sheets tabs depending on site and annotation. |
| TOP-017 | Topic page header | The topic header shows the title, category link, description, image on mobile and sponsorship dedication, with an AI disclosure marker when relevant. |
| TOP-020 | Topic page tabs | Topic pages have tabs for notable sources, all sources, top citations, sheets and (for authors) Works on Sefaria, plus filter and language controls. |
| TOP-022 | Topic source filter and sort | Readers can filter a topic's sources by text and sort by relevance, date or views. |
| TOP-023 | Topic source cards | Each source on a topic page shows the text excerpt with its citation, and curated sources show a title and learning prompt. |

| ID | Feature | What it does |
|---|---|---|

| TOP-005 | Topic word cloud (salad) | A colorful cloud of randomly chosen topic names links straight into topics. |

| TOP-011 | Topics category grid (Voices) | The Voices site's topics home is a grid of topic category cards plus an All Topics A-Z card. |
| TOP-012 | Topic card | A card represents a topic or category with title, description and link. |
| TOP-014 | All Topics A-Z index | An alphabetical index of every topic with letter navigation and a filter box. |

| TOP-021 | Topic source incremental loading | Topic source lists load in batches as the reader scrolls and remember how far they were scrolled on return. |
| TOP-024 | Topic sheet cards | Sheets tagged with a topic appear as cards with title, summary, author and save/follow actions. |
| TOP-025 | Topic side column: metadata and links | The side column shows the topic image, lifespan, external reference links and related-topic groups. |
| TOP-026 | Parasha readings panel | A Torah portion topic shows the next reading date, aliyot, and haftarah links. |
| TOP-030 | Topic data model behaviors | The client relies on topic fields for display gating, ordering, images and link groupings. |
| TOP-031 | Topic pool and trending endpoints | Server endpoints provide pooled random topics, trending topics and topic lists per site. |
