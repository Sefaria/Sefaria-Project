## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `sheets-view`): **27 features** — core 9, standard 12, optional 5, retire 1. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Sheet viewer (13); Sheet options menu (6); Entry points (4); Shared components (2); Sheets with ref (1); Sheet topics (1).

### Core (9)

| ID | Feature | What it does |
|---|---|---|
| SHV-001 | Voices sheets home page | The Voices home page shows a hero video banner, user-created content browsable by topic, and sidebar promos for creating a sheet. |
| SHV-002 | Sheet URL routes and legacy redirects | Sheets, collections and profiles have stable URLs on the Voices site, with old URLs redirecting to their current homes. |
| SHV-003 | Sheet page server rendering and indexing | Sheet pages are rendered server-side with title, description and breadcrumbs, and are hidden from search engines unless public. |
| SHV-004 | Sheet panel client routing and history | A sheet opens as a reader panel with its own URL, title and history entry, and warns before closing with unsaved edits. |
| SHV-005 | Read a source sheet | Anyone can read a source sheet in the reader with its sources, comments, headers and media, plus an author sidebar. |
| SHV-007 | Source blocks in sheets | Sheet sources show Hebrew and English text with a category-colored border, optional custom title and a link to the source in the library. |
| SHV-008 | Comments, headers and outside text | Sheets can include the author's own text: comments, section headers, free text, and two-column bilingual text. |
| SHV-018 | Sheet options (...) menu | A '...' menu on each sheet offers Save, Copy, Add to Collection, Export to Google Docs, Share, and owner actions. |
| SHV-026 | Sheet and collection listing components | Reusable list rows show sheets, collections and people consistently across profile, collections, saved and search. |

### Standard (12)

| ID | Feature | What it does |
|---|---|---|
| SHV-006 | Link handling inside sheets | Links inside a sheet open sensibly: Sefaria sheet links stay in the app, other links open in a new tab. |
| SHV-009 | Embedded media in sheets | Sheets can display images, YouTube, Vimeo, SoundCloud, Spotify and mp3 audio with optional bilingual captions. |
| SHV-010 | Highlight and scroll tracking in sheets | The current sheet segment is highlighted and scroll position updates the highlight and connections sidebar. |
| SHV-011 | Add sheet node to my sheet | Readers can copy any sheet node into one of their own sheets from the highlighted node. |
| SHV-012 | Sheet sidebar: author and topics | The sheet sidebar shows the author with follow button, bio, followers, topics and collections the sheet belongs to. |
| SHV-013 | Sheet display settings (language, layout, size) | Readers set sheet language and font size through the reader display menu; layout only applies when bilingual. |
| SHV-017 | Sheet view counts | Each sheet tracks how many times it was viewed and shows the count (or a lock for private sheets) in listings. |
| SHV-019 | Share sheet | Users can copy a sheet link or share it on Facebook, X or email. |
| SHV-020 | Copy sheet | Users can make their own unlisted copy of any sheet. |
| SHV-021 | Save sheet to my saved items | Users can bookmark a sheet to their Saved list from the options menu. |
| SHV-023 | Delete sheet | Owners can delete a sheet after confirming; they are returned to their profile. |
| SHV-024 | Sheets-with-ref page | A page lists community sheets that cite a given text reference, with filters and sorting. |

### Optional (5)

| ID | Feature | What it does |
|---|---|---|
| SHV-014 | Sheet display options ignored by React viewer | Per-sheet display options saved with a sheet (numbering, boxing, layout, language, divine names, BS"D) are not honored by the React viewer. |
| SHV-016 | Sheet likes (API only) | Sheet likes exist in the backend and trigger notifications to the owner, but the React viewer has no like button. |
| SHV-022 | Export sheet to Google Docs | Owners and readers can export a sheet to their Google Drive as a Google Doc. |
| SHV-025 | Sheet topic and tag lists | Public APIs list sheet topics alphabetically, by count, and trending. |
| SHV-027 | Sheet Google auth routes | Google OAuth endpoints connect and disconnect a user's Google account for sheet export. |
