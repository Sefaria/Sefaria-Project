## Baseline: what sefaria.org does today

From the Feature Atlas (`reader-next/docs/features`, area `ai`): **20 features** — standard 6, optional 14. Tiers are the audit's proposal (core: can't launch without it; standard: parity, can follow; optional: niche or rethink; retire: unused, broken or superseded).

Feature groups: Library Assistant (6); Guided Learning (3); AI Translation POC (3); Chatbot (2); AI translation POC (2); Guide overlay (1); Linker disambiguation (1); Assistant (1); AI disclosure (1).

### Standard (6)

| ID | Feature | What it does |
|---|---|---|
| AI-001 | Chatbot experiment banner (shell mount) | A site-wide banner invites eligible users to try the Library Assistant. |
| AI-003 | Chatbot user token and props | The server issues a short-lived encrypted token identifying the user to the assistant service. |
| AI-004 | Library Assistant opt-in, setting and promo banner | Users opt in to the assistant from a banner, signup flow or account settings; the setting falls back to the old experiments flag. |
| AI-008 | AI disclosure tooltip on Guided Learning | A tooltip tells readers that guide questions and answers were AI-generated. |
| AI-011 | Library Assistant chatbot widget | Eligible users on the Library module get a floating AI assistant chat widget embedded in the reader. |
| AI-017 | AI info tooltip | AI-generated content is marked with a star icon whose tooltip explains it and links to learn more and give feedback. |

### Optional (14)

| ID | Feature | What it does |
|---|---|---|
| AI-002 | Library Assistant promo banner | A banner invites users to try the Library Assistant, with a polite 'maybe later' backoff. |
| AI-005 | Chatbot preview build selection (?chatbot_version) | Developers can load a preview build of the assistant by URL parameter, remembered for the session. |
| AI-006 | Experiments opt-in plumbing and admin | Users can be enrolled in experiments by self opt-in or by staff CSV upload, and opt-ins notify the CRM. |
| AI-007 | Guide overlay and guide button | A bulb button opens an in-product guide for the sheet editor. |
| AI-009 | Quick Start guide overlay (guides app) | First-time users of the sheet editor see a carousel of tip cards with text and video; they can reopen it later. |
| AI-010 | Guided Learning box (experiment) | An experimental connections-panel mode shows key questions, summaries and commentary prompts for a ref. |
| AI-012 | Chatbot version override via query param (POC) | Developers can pin the chatbot preview server version with a URL param. |
| AI-013 | Linker LLM disambiguation visibility | LLM-based citation disambiguation results are visible to moderators in Linker Admin. |
| AI-014 | Per-segment AI translation QA controls | On a branch-only proof of concept, readers can mark an AI translation as reading well or report a problem on each segment. |
| AI-015 | Reader feedback on AI translations (branch) | Readers can double-click a word in an AI translation to suggest a correction, reviewed by staff. |
| AI-016 | Try Assistant button in Resources (branch) | A highlighted 'Try Assistant' button in the Resources panel opens the Library Assistant modal. |
| AI-018 | Community QA for AI translation (poc-translation) | On a non-merged branch, machine-translated text gets 'Reads well' and 'Report a problem' controls so readers can flag AI translation quality. |
| AI-019 | Shared chatbot version resolution (poc-translation) | A fix on the branch makes the preview chatbot version apply consistently to script URL and API base. |
| AI-020 | Other POC branches (names only) | The repo has other unmerged proof-of-concept branches not inspected. |
